# frankvogt.saarland

Diese Website ist für GitHub Pages aufgebaut. Die Galerien werden mit Jekyll automatisch aus den Bilddateien in den jeweiligen Unterordnern erzeugt.

**Fotos hochladen:** einfach JPG, JPEG, PNG oder WebP in den passenden Galerieordner hochladen. Keine HTML-Datei muss dafür geändert werden.
