# frankvogt.saarland

Statische Fotografie-Website für GitHub Pages.

## Dateien
- `index.html` – Startseite und Kapitelstruktur
- `style.css` – Design
- `script.js` – mobile Navigation und Header
- `galerien/` – Unterseiten für Galerien
- `bilder/` – eigene Fotos

## Fotos einsetzen
Lege deine Bilder in die vorgesehenen Ordner. Für die Startseite sind zunächst folgende Dateien vorgesehen:
- `bilder/start/hero.jpg`
- `bilder/start/foto1.jpg`
- `bilder/start/foto2.jpg`
- `bilder/start/foto3.jpg`
- `bilder/start/foto4.jpg`

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → Branch `main` → Folder `/ (root)`.

Danach unter Custom domain die Domain `frankvogt.saarland` eintragen und beim Domainanbieter die DNS-Einträge gemäß der aktuellen GitHub-Pages-Dokumentation setzen.
